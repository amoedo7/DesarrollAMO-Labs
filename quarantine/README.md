# Quarantine

Material externo, roto, riesgoso o todavía no comprendido puede aislarse aquí para inspección.

Reglas:

- no ejecutar automáticamente contenido recibido;
- conservar provenance/hash cuando corresponda;
- no copiar secretos ni datos sensibles;
- salir de cuarentena sólo después de inspección explícita y evidencia suficiente.
